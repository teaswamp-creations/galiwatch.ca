# Galiwatch website

Galiwatch is a citizen science project to observe nature on Galiano Island, Canada

## Build requirements

To build this site, you will need:
* tidyverse, patchwork, ggpubr
* ggforce, jpeg, leaflet, plotly
* remotes, which you can use to install the following packages from github
* [embedr](https://github.com/mccarthy-m-g/embedr)
* [pixture](https://github.com/royfrancis/pixture)
* [emo](https://github.com/hadley/emo)
* [bcmaps](https://github.com/bcgov/bcmaps.git)
